## ✨ Features
- ⚡ **Zero-build static** — HTML5 / CSS3 / modern vanilla JS (no heavy framework). Loads < 100ms, Lighthouse 95+ .
- 🎨 **Premium UI** — dark/light theme, glassmorphism, animations, fully responsive (mobile-first)
- 🔗 **GitHub-aware** — auto-fetches your 26 repos via GitHub API + Python generator (`tools/fetch_github.py`)
- 🔍 **SEO & perf** — semantic HTML, Open Graph, JSON-LD, sitemap ready, lazy images
- 🚀 **GitHub Pages ready** — one-click deploy via `gh-pages` branch or Actions workflow

## 🧰 Stack
- **Frontend:** HTML5, CSS3 (variables, grid, flex), Vanilla JS (ES2023)
- **Tooling (Python):** `tools/fetch_github.py` uses `requests` to generate `data/projects.json` from your GitHub — proves Python usage without needing a server on Pages
- **Hosting:** GitHub Pages (static). No server required. Works perfectly there.
- **Why not Flask/Django on Pages?** Pages is static-only. So we keep the site static for Pages, but provide Python tooling you can run locally/CI to keep projects fresh. If you later want backend, deploy same code to Render/Vercel in 1 command (see below).

## 🚀 Quick Start (local)
```bash
# 1. clone (after you create GitHub repo)
git clone https://github.com/OPBSUTHAR/MyByte.git
cd MyByte

# 2. run locally — just open index.html or use a server
python -m http.server 8000
# -> http://localhost:8000

# 3. (optional) refresh projects from GitHub via Python
pip install requests
python tools/fetch_github.py
```

## 🌐 Deploy to GitHub Pages (3 steps)
1. Create repo on GitHub named **MyByte** (https://github.com/new)
2. Push:
```bash
git remote add origin https://github.com/OPBSUTHAR/MyByte.git
git branch -M main
git push -u origin main
```
3. Enable Pages: GitHub → Settings → Pages → Source: **GitHub Actions** (workflow auto-deploys). Your site will be live at `https://opbsuthar.github.io/MyByte/`.

> Alternative: Settings → Pages → Branch: `main` / `(root)` — also works since it's pure static.

## 🐍 Python Power
